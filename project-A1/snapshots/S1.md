## 阶段摘要

确定了使用网页账号通过手动触发的书签脚本将对话快照同步到 GitHub 私有仓库的方案，制定了完整对话文件覆盖存储和分层快照结构，并支持多项目管理。

## 关键决定

- 使用网页账号（非官方 API），通过浏览器书签脚本手动抓取对话，避免违规的自动逆向接口
- 将快照和完整对话上传至 GitHub 私有仓库，采用覆盖完整文件而非增量存储以便快速回溯
- 采用 Bookmarklet 方式实现“一键同步”，兼容 Chrome、Edge、Brave、Firefox（Safari 可能受限）
- 在仓库中按项目划分文件夹，实现多项目记忆管理
- 放弃 Claude Exporter 扩展，因其不提供 API 且非官方

## 踩坑记录

- 非官方抓取可能被平台封禁 → 采用手动触发的书签脚本，降低频率和风险
- Safari 对网络请求的 Bookmarklet 限制 → 主要使用 Chrome/Edge/Brave/Firefox，必要时单独测试 Safari
- Claude Exporter 不支持 API → 完全自行实现同步脚本

## 遗留问题

- 设计并实现项目选择交互（弹窗或多书签方案）
- 完成脚本的安全审计与使用说明文档
- 在实际对话中验证快照格式与云端读取流程的可行性
